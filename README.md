# Python

Repositório dedicado ao aprendizado e prática de Python, com exercícios e pequenos projetos focados em lógica, cálculos, automação e soluções úteis para o dia a dia.

## Objetivo

Explorar conceitos fundamentais da linguagem Python por meio de projetos práticos, reforçando habilidades como:

- variáveis e entrada de dados
- estruturas condicionais
- laços de repetição
- funções e modularização
- manipulação de strings e listas
- lógica de programação
- resolução de problemas reais

## Conteúdo

Este repositório reúne uma coleção de projetos e exercícios voltados para:
- aprendizagem prática
- desenvolvimento de raciocínio lógico
- criação de scripts simples e funcionais
- estudo contínuo da linguagem Python

## Tecnologias

- Python 3
- Estruturas de controle
- Funções e operações básicas
- Manipulação de dados e lógica de programação

## Como executar

1. Clone o repositório:
```bash
git clone https://github.com/joaoricardovieiraaraujo/Python.git
```

2. Acesse a pasta do projeto:
```bash
cd Python
```

3. Execute qualquer script Python:
```bash
python nome_do_arquivo.py
```
